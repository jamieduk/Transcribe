
Transcribe Skill

Use the script scripts/transcribe/start.sh with a youtube url link passed as the argument to get transcription text and post the whole trnanscription text in chat response, allow the transcription file generated by the script to be downloaded by the use.

Example of script usage:

scripts/transcribe/start.sh "https://www.youtube.com/watch?v=P70HtcWP7PY"
